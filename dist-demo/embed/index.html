方式 A · embed 内嵌（单文件 SDK）

宿主提供数据源模板（字段结构）与设计模版（版式 JSON）。 设计阶段用 defineDataSource + defineTemplates 登记，不写业务数据。 预览·打印阶段用 load 打开画布：必须同时带上设计模版 id与数据源模板 id；之后只换数用 setData({ data })，不要再传 dataSourceId。 库样例经 DemoAssets.loadCatalog() 读 demo/bundle.js（真源 src/assets/library）。

推荐接入顺序
步骤调用作用
1 mount('#designer', { mode }) 挂载 SDK（同步首屏，返回即可调 api）
2 defineDataSource + defineTemplates 设计：登记字段树 + 模版 JSON
3 load({ templateId, dataSourceId, data? }) 预览·打印：两 id 必填，打开唯一入口
4 setData({ data }) / 预览·打印 API 换业务数据或输出 HTML / 打印

mount / unmount

单页仅一个实例；再次 mount 会先卸掉上一个。正式产物目录：dist-demo/（npm run build:sdk），脚本 ../sdk/iprint-designer.js。

<script src="../sdk/iprint-designer.js"></script>
const instance = IPrintDesigner.mount('#designer', { mode: 'free', height: '100%' });
// instance.element · instance.layoutMode · instance.unmount()
IPrintDesigner.unmount();

defineDataSource

设计 · 登记数据源模板（可多次；同 id 覆盖）。fields 与数据源面板同形；业务数据不要写在这里。

const r = api.defineDataSource({
  id: 'erp_purchase',
  name: '采购单',
  fields: [
    { name: '采购单号', field: 'billNo' },
    { name: '明细', field: 'lines', kind: 'array', fields: [
      { name: '货号', field: 'sku' },
    ]},
  ],
});
// → { ok: true, id, name, fieldCount, arrayPaths }

defineTemplates

设计 · 登记 1～N 份设计模版（同 id 覆盖；不打开画布）。模版对象来自宿主持久化或 DemoAssets。

const catalog = await DemoAssets.loadCatalog();
const meta = DemoAssets.findTemplate(catalog, 'document-purchase');
const template = await DemoAssets.readTemplate(meta);

api.defineTemplates({ templates: [template] });
// → { ok: true, templateIds: ['document-purchase'] }

load

预览·打印 · 打开设计模版并绑数据源模板。templateId 与 dataSourceId 均必填；data 可选。

api.load({
  templateId: template.id,        // 必填 · 设计模版
  dataSourceId: 'erp_purchase',   // 必填 · 数据源模板
  data: { billNo: 'CG001', lines: [] }, // 可选
});
// → { ok: true, templateId, dataSourceId }

setData

预览·打印 · 只换当前页业务根对象；不要传 dataSourceId。

api.setData({ data: { billNo: 'CG002', lines: [{ sku: 'S-1', qty: 3 }] } });
// → { ok: true }

openPreview / closePreview

设计器内置打印预览 Modal（导出 HTML/PDF/打印）。与宿主自建「逐元素预览」互斥，打开前请先关掉另一侧遮罩。

api.closePreview();
api.openPreview();  // → { ok: true }
api.closePreview(); // → { ok: true }

getPreviewData

逐元素预览：页 + 几何 + 已绑定数据的 html / text（页内坐标）。

api.closePreview();
const data = api.getPreviewData();
// data.pages[].elements[] → x, y, width, height, html, text, …

getPrintPages

分页打印稿：css、每页 pages[] 片段、完整 document HTML。

const { document, css, pages } = api.getPrintPages();
const blob = new Blob([document], { type: 'text/html;charset=utf-8' });

print

在用户点击事件链里直接调用，调起系统打印对话框。

document.getElementById('btnPrint').onclick = () => api.print();
// → { ok: true }

ping

连通性与版本（SDK：IPrintDesigner.api.ping() 或 IPrintDesigner.version）。

const { version } = IPrintDesigner.api.ping();
// → { ok: true, version: '…' }（同 IPrintDesigner.version）

典型链路

与本 DEMO 左侧面板一致：先 define，再 load（两 id），应用数据走 setData。

const catalog = await DemoAssets.loadCatalog();
const template = await DemoAssets.readTemplate(
  DemoAssets.findTemplate(catalog, 'document-purchase'),
);
const schema = await DemoAssets.readDataSourceSchema(catalog, template.dataSourceId);
const sample = await DemoAssets.readSample(catalog, template, schema.id);

IPrintDesigner.mount('#designer', { mode: 'free' });
api.defineDataSource({ id: schema.id, name: schema.name, fields: schema.fields });
api.defineTemplates({ templates: [template] });
api.load({
  templateId: template.id,
  dataSourceId: schema.id,
  data: sample.data,
});

api.openPreview();
