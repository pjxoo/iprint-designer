方式 B · iframe + postMessage

与 SDK 共用同一份 hostApi 能力；设计器跑在 iframe / 内，宿主通过 postMessage 调用。 设计：defineDataSource + defineTemplates。 预览·打印：load 须设计模版 id + 数据源模板 id；换数仅 setData({ data })。 样例数据经 DemoAssets.loadCatalog() 读 bundle。 本页须 http(s)，勿用 file://。

推荐接入顺序
步骤调用作用
1 等 ready → await call('ping') 握手后再发业务指令
2 defineDataSource + defineTemplates 设计：登记字段树 + 模版 JSON
3 load({ templateId, dataSourceId, data? }) 预览·打印：两 id 必填
4 setData({ data }) / 预览·打印 换业务数据或输出

iframe / call / ping

收到 { type: 'ready' } 后再 call。请求名与 SDK 方法同名；返回 Promise。

<iframe id="designer" src="/"></iframe>

// 宿主 → { source: 'i-print-host', type, requestId, payload }
// 设计器 → { source: 'i-print-designer', type: 'response', requestId, ok, result }

const { version } = await call('ping');
// → { ok: true, version: '…' }

defineDataSource

设计 · 登记数据源模板；不写业务数据。

await call('defineDataSource', {
  id: 'apparel',
  name: '收银',
  fields: [{ name: '单号', field: 'billNo' }],
});
// → { ok: true, id, name, fieldCount, arrayPaths }

defineTemplates

设计 · 登记设计模版（来自宿主或 DemoAssets）。

const catalog = await DemoAssets.loadCatalog();
const template = await DemoAssets.readTemplate(
  DemoAssets.findTemplate(catalog, 'ticket-pos'),
);
await call('defineTemplates', { templates: [template] });
// → { ok: true, templateIds: ['ticket-pos'] }

load

预览·打印 · templateId + dataSourceId 必填；data 可选。

await call('load', {
  templateId: template.id,
  dataSourceId: 'apparel',
  data: { billNo: 'T001', items: [] },
});
// → { ok: true, templateId, dataSourceId }

setData

预览·打印 · 只传 { data }，不传 dataSourceId。

await call('setData', { data: { billNo: 'T002' } });
// → { ok: true }

openPreview / closePreview

设计器内置预览 Modal；与宿主自建预览互斥。

await call('closePreview');
await call('openPreview');  // → { ok: true }

getPreviewData

逐元素预览数据（页内坐标 + html/text）。

await call('closePreview');
const data = await call('getPreviewData');

getPrintPages

分页 HTML + 完整 document。

const { document } = await call('getPrintPages');

print

须在用户点击回调里 await call('print')。

btn.onclick = async () => { await call('print'); };

ping

连接后探测版本（本 DEMO 在 connect 时调用）。

const { version } = await call('ping');
// → { ok: true, version: '…' }

典型链路

收银小票 DEMO：ready 后 define → load（两 id）→ setData。

const catalog = await DemoAssets.loadCatalog();
const template = await DemoAssets.readTemplate(
  DemoAssets.findTemplate(catalog, 'ticket-pos'),
);
const schema = await DemoAssets.readDataSourceSchema(catalog, template.dataSourceId);
const sample = await DemoAssets.readSample(catalog, template, schema.id);

await call('defineDataSource', {
  id: schema.id, name: schema.name, fields: schema.fields,
});
await call('defineTemplates', { templates: [template] });
await call('load', {
  templateId: template.id,
  dataSourceId: schema.id,
  data: sample.data,
});
